# Value ledger — pipeline_b

Per-feature cost/yield tracking, per the standing agreement: every
feature gets a row **when it is built**, with *predicted* yield written
at implementation time. Optional features predicted marginal get
same-seed on/off ablation pairs in the next gallery. An indispensable
core mechanism uses a documented counterfactual or calibrated probe
rather than a fictitious user-facing off switch. *Observed* yield is
recorded at review. The ledger nominates trims; **only the author decides them.**
A milestone is not done until its rows are current.

The complete private-attempt chronology, including abandoned designs and
superseded historical gates, is indexed in
[`ATTEMPT_REGISTER.md`](ATTEMPT_REGISTER.md). Production milestone state is
in [`MILESTONES.md`](MILESTONES.md).

Yield is stated in terms of contract sections served (e.g. "§6c shelf
variety") and canon qualities (§12 list). Cost includes runtime cost at
the §15 tiers where it matters.
